    Variable & Session Management¶

    Function Description
    AddToSession Stores a non-object, non-array value in the current session under a string key.
    ClearSession Clears all values from the current session.
    CreateLocal Creates or overwrites a local variable in the current scope by name.
    CreatePublic Creates or overwrites a public variable by name.
    GetByName Retrieves the value of a variable by name from the current scope, a caller scope, or public storage.
    GetFromApplication Returns a comma-separated string of connected usernames when called with the special key "STARLIMSUSERS" in a CUSTOM session context.
    GetFromSession Retrieves the value associated with a specified key from the current user session.
    GetSetting Retrieves the stored value of a named configuration setting.
    GetSettings Retrieves multiple named settings in one call.
    IsDefined Determines whether a variable name is currently defined.
    LKill Deletes a public variable from the current SSL session by name and returns an empty string.
    SetByName Assigns a value to a variable whose name is supplied at runtime.
