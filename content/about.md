# About This Reference

## What this is

An **unofficial** reference for the STARLIMS Scripting Language (SSL), built
from many years of personal notes and observations from working with
**STARLIMS version 11**. It collects function signatures, class members,
keyword and operator behavior, type information, and code examples into a
single browsable site.

## What it documents

Everything here describes SSL **as observed in STARLIMS version 11**. Other
versions may behave differently — if you are on a different version, verify
behavior in your own environment before relying on a page.

## How it was built — and why you should double-check

The documentation was drafted with the help of AI tools, working from the
maintainer's notes, and then reviewed. Even so, some pages will contain
mistakes: a signature that drifted, an edge case that doesn't reproduce in
your environment, an example that was never run against your configuration.

**Take the content here with a grain of salt and use it at your own risk.**
When a page disagrees with what your system actually does, trust your system
— and please tell us.

## Reporting problems

If you spot something wrong, unclear, or missing:

- [Open an issue](https://github.com/mahoskye/starlims-ssl-reference/issues)
  describing the page and the behavior you observed, or
- use the **edit icon** at the top of any page to propose a fix directly.

Corrections from working SSL developers are the main way this reference gets
better.
